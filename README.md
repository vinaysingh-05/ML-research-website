# Machine Learning Research Paper Website

A professional interactive research paper website exploring **"What is Machine Learning Actually Good For — and When is a Plain Rule Better?"**

This project presents fundamental Machine Learning concepts in the form of a modern academic website suitable for research presentations, internships, portfolios, and GitHub Pages deployment.

---


# Features

* Interactive research paper website
* Modern responsive UI
* Professional academic layout
* Sticky navigation
* Table of contents
* SVG illustrations
* Chart.js interactive graphs
* Dark & Light Mode
* Reading Progress Indicator
* Smooth scrolling
* Mobile responsive
* SEO optimized
* Accessibility friendly
* Download PDF support
* GitHub Pages compatible

# Installation

Clone the repository:

```bash
git clone 
```

Open:

```text
index.html
```

# Deployment

Push the repository to GitHub.

Enable **GitHub Pages** from:

Settings → Pages → Deploy from Branch → main → /(root)
